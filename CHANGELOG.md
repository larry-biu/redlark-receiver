# Changelog

## 1.4.1

- Accept an optional Vault-relative attachment folder from RedLark Clipper.
- Continue using Obsidian's configured attachment location when that field is
  empty, preserving existing behavior and user settings.

## 1.4.0

- Focus the plugin on one job: receive one active-page capture from RedLark
  Clipper and write it into the current Vault.
- Move Xiaohongshu and Feishu/Lark note folder settings to the Chrome extension.
- Always use Obsidian's default attachment location for images.
- Remove the standalone Xiaohongshu import command, clipboard flow, plugin
  settings tab, and batch behavior.
- Preserve Xiaohongshu reading styles and verify note and attachment writes.
